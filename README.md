# MUSTAFA LLC — Enterprise Technology, Cloud & Strategic Advisory

A high-performance, modern corporate landing page and web application built with semantic HTML5, modern CSS3 (Glassmorphism & animations), and dynamic Vanilla JavaScript.

## 🚀 Features

- **Executive Aesthetic:** Curated dark mode theme with neon cyan & purple gradients, glassmorphism card components, and Google Fonts typography.
- **Interactive Observability Hub:** Real-time simulated telemetry wave rendered on HTML5 Canvas with live metric updates and load-surge simulation.
- **Dynamic ROI & Scope Estimator:** Interactive calculation engine allowing prospects to model operational impact, timelines, and deliverables.
- **Executive Discovery Modal:** Interactive consultation scheduler with window selector.
- **Contact Suite:** Real-time field validation, budget tier selector, and asynchronous submission state.
- **Responsive Architecture:** Fully responsive across mobile, tablet, desktop, and ultra-wide screens.

## 📁 Project Structure

```
├── index.html                 # Semantic HTML5 architecture & SEO metadata
├── style.css                  # Curated dark palette, glassmorphism, responsive styles
├── script.js                  # Dynamic widgets, telemetry canvas, ROI calculator
├── server.js                  # Zero-dependency local Node.js static preview server
└── assets/
    └── images/
        ├── hero-tech.jpg      # High-definition 3D tech isometric visualization
        └── about-network.jpg  # Global headquarters and operations visual
```

## 🛠️ Local Development

To run the local preview server:

```bash
node server.js
```

Then visit [http://127.0.0.1:4173/](http://127.0.0.1:4173/) in your web browser. Or simply open `index.html` directly.
